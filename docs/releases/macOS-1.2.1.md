# Dday 1.2.1

## 한국어

- macOS 27에 맞춰 메뉴 막대 배지 렌더링을 개선했습니다. 밝은 모드·어두운 모드와 ‘대비 증가’, ‘투명도 줄이기’ 설정 변경이 바로 반영됩니다.
- 사용자 D-Day 선택과 복원을 수정하고, 학회 데이터를 불러오지 못했을 때 재시도와 사용자 일정 추가를 제공하도록 개선했습니다.
- 메뉴와 배지의 불필요한 반복 갱신을 줄였습니다.
- NAACL, COLING, EACL, AISTATS, ALT, CVPR, ICAPS 2027 등 발표된 학회 일정을 반영했습니다. 날짜가 확정되지 않은 마감은 추가하지 않았습니다.

Apple Silicon Mac, macOS 13 이상을 지원합니다. DMG를 열어 Dday를 응용 프로그램 폴더로 옮겨 주세요. 기존 사용자는 앱의 업데이트 확인 기능으로 업데이트할 수 있습니다.

## English

- Improved menu bar badge rendering for macOS 27, with immediate updates for light and dark appearance, Increase Contrast, and Reduce Transparency.
- Fixed custom deadline selection and restoration, and improved recovery when the conference catalog cannot be loaded.
- Reduced unnecessary menu and badge refreshes.
- Updated announced conference deadlines, including NAACL, COLING, EACL, AISTATS, ALT, CVPR, and ICAPS 2027. Unannounced deadlines are omitted.

Requires an Apple Silicon Mac running macOS 13 or later. Open the DMG and drag Dday to Applications. Existing users can use Check for Updates in the app.
